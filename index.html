¿Por qué elegirnos?

  • Una alternativa activa para conocer la ciudad.
  • Opciones de bicicletas para diferentes necesidades.
  • Casco y candado incluidos durante el alquiler.
  • Recorridos para diferentes niveles de experiencia.

¿Cómo alquilar?

  1. Consulta las bicicletas y las tarifas disponibles.
  2. Elige la duración del alquiler y, si quieres, un recorrido.
  3. Completa el formulario de reserva.
  4. Espera la confirmación antes de presentarte.
