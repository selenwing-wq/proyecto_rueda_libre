5. FUNCION DE HTML, CSS Y JAVASCRIPT

HTML:
Define la estructura y el contenido de la pagina.
Ejemplo: <h1>Rueda Libre</h1> muestra el titulo principal.

CSS:
Controla la apariencia visual de la pagina.
Ejemplo: h1 { color: green; } cambia el color del titulo.

JavaScript:
Agrega interactividad y comportamiento.
Ejemplo: un boton que muestra un mensaje al hacer clic.
